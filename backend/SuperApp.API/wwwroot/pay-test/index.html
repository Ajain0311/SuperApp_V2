How to attach keys
  • Open dashboard.razorpay.com
  • Turn Test Mode ON
  • Settings → API Keys → Generate Test Keys
  • Set env vars PAYMENT_KEY / PAYMENT_SECRET or Payment:Key / Payment:Secret in appsettings.Development.json
  • Set PAYMENT_PROVIDER=Razorpay and restart the API
